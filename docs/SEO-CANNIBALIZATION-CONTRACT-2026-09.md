# PlushTrap Search Cannibalization Contract

## Intent ownership

| Intent | Primary owner |
|---|---|
| exact 1/3/5-hole configuration | exact PDP |
| exact bunny/rabbit-ear configuration | exact PDP |
| exact stable color + configuration | exact PDP/variant canonical |
| broad streetwear/kawaii/fashion balaclava | balaclava collection |
| bunny-ear browsing | bunny collection if enough real products exist; otherwise strongest PDP |
| camo browsing | camo collection if enough real products exist; otherwise strongest PDP |
| outfit/how-to-style queries | editorial/style page |

Rules:
- Do not index every filter permutation.
- Do not make collection, PDP, and article share the same primary phrase.
- Preserve opening count, ears, color, pattern, and verified construction in product metadata because these are buyer-disambiguating attributes.
- Historical Shopify identifiers/data never decide current canonical ownership.
- Stripe-backed current price/product identifiers and current site product facts must agree before volatile offer data is published.
- Real product photography should link editorial intent to the exact shoppable item shown.
