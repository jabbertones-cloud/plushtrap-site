# Google vs Microsoft SEO/AEO Charge — PlushTrap

Verified against current first-party guidance: 2026-09-06.

## Shared foundation

Google and Microsoft both benefit from canonical product ownership, crawlable public pages, current sitemaps, visible product facts, internal links and structured data that matches the storefront. Current Stripe/site runtime is commerce authority. Historical Shopify exports are never current SEO/AEO authority.

## Google charge

Google AI Overviews/AI Mode use normal Search foundations; no special AI markup or AI text file is required. Prioritize exact product-form language on canonical PDPs, rich original imagery, descriptive alt text, truthful variant/configuration attributes, and Product/Offer structured data synchronized with the live storefront. Pair Product structured data with Merchant Center once the full current catalog projection is reconciled.

Commercial intent should map to a few strong owners: exact 1-hole/3-hole/5-hole and bunny-ear configurations belong to exact PDPs; broad streetwear/kawaii/fashion balaclava browsing belongs to `/shop` or a real collection only when enough live products justify it.

## Microsoft/Bing/Copilot charge

Bing's current AI Performance model rewards becoming a cited source, not merely ranking. Track cited URLs, grounding queries, commercial/comparison intents, topics and citation share. Use IndexNow for changed canonical URLs only after the production key/host implementation is verified. Keep headings and product facts answerable without duplicating near-identical color/configuration pages.

## Content gap / new pages

The highest-value missing work is catalog completion, not blog volume. After current runtime reconciliation:

1. Exact canonical PDPs for every current live product/configuration.
2. One balaclava collection page owning broad `streetwear balaclava`, `fashion balaclava`, `cute/kawaii balaclava` browsing intent if the live catalog supports it.
3. One bunny-ear ski mask/balaclava collection only if multiple current products justify the category.
4. A useful `how to style a balaclava` editorial page using actual PlushTrap products and original imagery.
5. A configuration guide explaining 1-hole vs 3-hole vs 5-hole products without inventing functional/safety superiority.

Do not create color-keyword doorway pages.

## Completion gates

- Current Stripe-backed catalog owns sitemap/schema/feed membership.
- Every sitemap PDP is verified live and canonical.
- Google Merchant data and Product schema share current price/availability authority.
- Microsoft IndexNow is enabled only with a verified production key/host.
- Measure Google Search Console query/PDP conversion paths separately from Bing Search Performance + AI Performance citations/grounding queries.
