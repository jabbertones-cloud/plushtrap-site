# PlushTrap Current Commerce Authority Gate — 2026-09

Public SEO/AEO product facts must come from the current PlushTrap storefront/product registry reconciled with Stripe-backed commerce identifiers.

Historical Shopify exports are media/catalog migration references only. They must never supply current price, inventory, availability, canonical URL, sitemap membership, Product/Offer JSON-LD, Merchant Center fields, OpenAI merchant fields, or llms/facts assertions.

## Publishable product contract

A product can enter a discovery sitemap or commerce projection only when all required fields are verified from current authority:

- canonical public URL
- current product name
- current SKU or stable product identifier
- current sellable state
- current price/currency when an Offer is published
- exact visual/configuration attributes that are literally true (for example hole count, bunny ears, color, camo, bundle quantity)
- current checkout mapping to Stripe-backed commerce

Amazon identifiers are a separate channel identity. Duplicate or unresolved ASIN/SKU mappings must not be promoted as canonical product identity.

## Search-intent ownership

Use exact configuration language on the canonical PDP rather than cloning near-duplicate keyword pages. High-value families include 1-hole, 3-hole and 5-hole balaclavas; bunny-ear/bunny ski masks; camo balaclavas; DIY balaclavas; and verified color/configuration combinations.

Supporting editorial/category content may target streetwear balaclava, fashion balaclava, cute/kawaii balaclava, balaclava outfit and styling intent, but it should link to the current canonical product owner.

## Release gate

Do not restore a sitemap directive until a sitemap can be generated from the verified current product contract. A historical product dump passing a schema check is not publication proof.
